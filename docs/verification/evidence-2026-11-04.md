## Run independently against public Horizon

After `corepack pnpm install --frozen-lockfile`, execute:

```sh
RECLAIM_ORIGINAL_TX=72aee7d6750e03447eafd63f3330665ad8631e5023d3db5a4138c7231880f5a8 \
RECLAIM_PARTIAL_TX=dee132fc3d2d1a00bb5768671684b4b2a11077a56cddf893b3ccfbe109f6bcb1 \
RECLAIM_FINAL_TX=a171841fb86dbb5c8b0367ca2f3d46b34b3d9d382e2818197a008ad935902de7 \
RECLAIM_ORIGINAL_OP=0 RECLAIM_PARTIAL_OP=0 RECLAIM_FINAL_OP=0 \
node --experimental-strip-types --test tests/e2e/testnet-recovery.test.mjs
```

Each screenshot reports one operation, hence index 0. A passing test confirms
Horizon network identity, successful operations, matching reverse payment
direction and asset, partial and full amounts, refusal and mismatch safeguards.
A failing test requires investigation and **must not be bypassed** by editing
the expected outputs or mislabeling the transaction hashes.

Live network records can be inspected using `https://horizon-testnet.stellar.org/transactions/HASH`
and `https://horizon-testnet.stellar.org/transactions/HASH/operations`.
